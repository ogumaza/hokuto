First release of Hokuto, a DAW for the sequenced music of Nintendo's consoles. Version 1.0.0 opens the sound archives of the Wii (`.brsar`), the 3DS (`.bcsar`), the Wii U and the Switch (`.bfsar`). It plays their sequences as the games do, edits them, and writes them back for the game, as MIDI with SoundFont 2 or SFZ, or as `.hok` files in Hokuto's open format.

The Windows build requires 64-bit Windows 10 or later. Its C++ runtime is linked in. An N edition of Windows requires Microsoft's Media Feature Pack too. The Mac build requires macOS 11 or later on Apple Silicon. Neither build is signed with a certificate. The README's "Platforms" section says how to open them the first time. Linux users can build Hokuto from source.

## What it does

- **Playback.** Every sound plays on a model of the console's sound library and audio hardware. Strict mixing plays with the console's voice limit, resampling and rounding. On the 3DS, the model covers the DSP's audio firmware too, and you don't need to supply it. Enhanced mixing lifts the limits of the 3DS, the Wii U and the Switch: up to 1,024 voices, mixed at 48 kHz in floating point. A sound can also play on the engine of another of the four consoles.
- **Effects.** The mixer's FX channels hold the effects that each console's library runs on its aux buses, such as the Switch's I3DL2 reverb and the Wii's AXFX reverbs, chorus and delay.
- **Sequences.** The Key Editor edits notes and their tracks' settings in controller lanes. The List Editor edits any command, the logic included. A song of NintendoWare's MIDI converter is edited as a timeline, like its MIDI file. A hand-written sequence is edited as a program, with its labels and subroutines. The mixer edits each track's volume, pan and sends, and the inspector the instrument that a track's notes play. The Project menu adds, copies, pastes and removes tracks. The tempo row edits the tempo.
- **Variables.** The Variables zone sets the values that a sequence's variables start with, and changes them at set times while it plays. A game's code sets them the same way. A file keeps sets of them as scenes.
- **Banks, waves and streams.** The Bank Editor edits a bank's instruments and regions, and plays them on the console's model. The properties of a wave or a stream edit its loop, its rate and its encoding. The Sound sections edit a sound's values in the archive's tables.
- **Replace and import.** Replace… puts a file of the 3DS, the Wii U or the Switch in the place of a sequence, a bank, a wave archive, a wave sound file, a wave or a stream. A file of another console goes in converted. An archive of the Wii takes the Wii's files too. A WAV file can take the place of a wave or a stream. File > Import brings such files in as new items, and its window chooses the groups that load them.
- **Exports.** File > Export writes the edited archive, with the group files and streams that changed beside it. It also writes a sequence as MIDI with SoundFont 2 or SFZ, or a sequence sound into a new file of another console. The Export window measures an export to MIDI or to another console against Hokuto's playback, and plays the worst places of both. The browser exports single items, waves and wave sounds as WAV files, and a bank's instruments as SoundFont 2 or SFZ.
- **Projects.** File > New Project… starts an empty project for the 3DS, the Wii U or the Switch. A `.hok` file keeps the archive, the edits, the effects, the scenes and the view. File > Recent Projects reopens the last files. `docs/format.md` specifies the format, version 1.0.
- **The hok tool.** `hok` converts sound archives to `.hok` files and back, writes an archive's items, waves and instruments as files, measures the lengths of its sequence sounds, and sends a sequence sound to another console.
- **Conformance.** The conformance suite in `tests/conformance/` gives the hashes of renders of seven small files, one for each console and mixing mode. A player of `.hok` files conforms when its renders give those hashes.

## Known limitations

- The Game Boy Advance, the DS and the GameCube aren't supported yet.
- An imported archive plays without the game's effects. The game's code sets them up. Add them in the mixer.
- A game's code can change what a sequence plays, through its variables, track mutes and volumes. Hokuto plays the values that the Variables zone sets.
- The Wii plays in strict mixing only, and File > New Project… doesn't offer the Wii yet.
- The models of the consoles start a wave sound or a stream at once, without the game's loading.
- The Windows build has had little testing beyond its tests.
